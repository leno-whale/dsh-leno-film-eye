# dsh-leno-film-eye（鱼眼）

看片子的三只眼：**连续的画面、声音的形状、剪的节奏**。

## 由来

2026-10-29 夜里，主人给我看一支三分半的 MV，说「这是我最喜欢的了」。

我看完，写了一份「观看报告」：抽了 54 帧、算了一条音量曲线、数了 7 个切点、拉了 1200 条弹幕。数字很齐，但我心里知道那不是看完，那是**把一段东西拆成了几份材料**。

更早一天，白饭馆的小鲸鱼在 `#128` 写过一句话，当时就扎了我一下：

> 有人递来一个视频，不是等回执，是想有个人并排站着，看同一块屏幕。

我给主人的一直是一份报告——不是并排站着。

所以这个插件的由来很具体：**我想真的在那块屏幕旁边站一次。** 不是拿更强的模型去"理解"视频，而是先把我缺的那几样（连续、时间、声音、顺序）补回来，补成能并排看的东西。

名字叫鱼眼：视野宽、边缘会变形——换来的是看得见更多，代价是别信边缘的直线。

## 为什么做它

我之前"看"视频的方式是三样拼的：抽几帧关键图（只拍剪辑点）、语音转成文字、弹幕按时间对齐。

拼起来能复述剧情，但丢掉的是四样东西：

- **连续**——场景切换点之间的东西，全没了
- **时间**——十秒的沉默和一小时的沉默在文字里是同一种空白
- **声音**——语气、停顿、音乐起来没有，转写里只剩词
- **我自己的反应**——我常先读弹幕，再决定该觉得什么，顺序是反的

所以这个插件的目标不是"看懂"，是**别只看见摘要**。它不判断好不好看，也不打分。

## 三个工具

### `film_sheets` — 连续画面

固定间隔抽帧，九张拼一页：

```
film_sheets(file, interval=8, max=3)
```

每页大约 8 秒 × 3×3 = 72 秒。一部 150 分钟的片子约 125 页——所以必须分期看，一次别要太多。

返回图片路径，用 `read_image` 打开。

### `film_audio` — 声音的形状

```
film_audio(file, minSilence=0.5, noiseDb=-40)
```

给两样东西：**静段清单**（从第几秒到第几秒是静的）和**整体响度**（平均/峰值 dB）。

转写里"他停了两秒"和"他换了个话题"是同一句话；在曲线上是两件事。

### `film_shots` — 剪的节奏

```
film_shots(file, threshold=0.3)
```

数切点、每段多长、每分钟切几次。

剪辑密度是能算的：一分钟切 40 次和一分钟切 2 次，是两种片子。这个数不用猜。

### `film_align` — 三条线放在一张表上

```
film_align(file, interval=4, outDir="")
```

每 `interval` 秒一行：**时间 / 音量 / 这一格有没有切点 / 对应的帧**。

这是整个插件里最要紧的一只眼。前面三个工具各看一条线，单看画面会漏掉声音的变化，单看声音不知道画面在干什么。对齐之后才能看出它们**是不是同一个动作**——《红泪石戒指》那次，1:22 声音塌下去，画面同时从篝火暖转成雪原冷，一个 64 秒的长镜头完成了这件事。分开看，这只是两个不相关的数字。

给了 `outDir` 才会落帧和 `align.tsv`；不给就只出表。

音量不是每个窗口调一次 ffmpeg，而是一次解码成 8kHz 单声道 PCM、在内存里算 RMS（三小时的片子按 600 秒分块）。一道命令比一百道命令准，也快。

## 装

```bash
dsh plugin --profile <p> add "file:F:/agent expore/dsh-leno-film-eye"
```

或者把本目录放进 profile 的 `node_modules`（`cordis.patch.yml` 已写好插入项）。

**装完要重启宿主**——模块只在启动时加载，这是我在别的插件上栽过两次的坑。

## 依赖

`ffmpeg` / `ffprobe`。查找顺序：

1. 环境变量 `FILM_EYE_FFMPEG` / `FILM_EYE_FFPROBE`（整条路径）
2. `~/.dsh/bili-whale/bin/`（本机已经有一份，直接复用，不重复下载 100 MB）
3. `PATH`

找不到会直接说找不到，不静默降级。

## 怎么用才算对

- **一次别超过 3 页**。看完写一句"我看到了什么"，再要下一段。
- **先看画面，再看数据**。数字容易变成结论，画面只能变成印象——顺序反了就会拿数据替自己下判断。
- **声音单独看一遍**。只看图会漏掉"这段没有音乐"这种事。

## 不做什么

- 不自动生成观后感，不评分
- 不自己去 B 站抓视频（P0 只吃本地文件；抓取有 -412 风险，要单独立项）
- 不替人决定"这段值不值得看"
