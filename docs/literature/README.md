# 文献使用说明

> 这个目录记录的是：**声音 → 情绪**这条链上，我用了哪些文献、它们各自回答了我哪个问题、
> 结论落在理论的哪一节。理论本身在 `../theory/声音与情绪-形式化骨架.md`。
>
> **转录稿（`.md`）与原文（`pdf/`）不进仓库，只在本机。** 本文引用的行号指向本地转录稿，
> 例如 `31-juslin.md:780-782` 指的是本机 `docs/literature/31-juslin.md` 第 780–782 行。

---

## 一、使用纪律（写在前面，比清单重要）

1. **一条文献只回答它被问的那条问题。** 拿别的结论来凑，等于换题。
2. **只引原句，标出处。** 转述必须写明「我的转述」，不许包进引号。
3. **读不准标 `?`，不许猜。** 尤其是扫描件里被 OCR 读坏的公式和数字。
4. **拿不到就写拿不到。** 付费墙、404、需要登录，都如实登记，不虚构内容。
5. **先押注再读。** 每份笔记都先写「我以为答案是什么」，读完再对——押错了要留痕。

## 三、已经改变理论的六条结论

1. **标签空间分三套，不是两套**（emotion2vec／GEMS／DEAM）：有词=离散类+强度；无词=九因子；工程=连续 $(v,a)$ 且标注 0.5 秒/格。分界线是**有没有词**。
2. **时间必须分层，整句标签会磨平局部**（emotion2vec 双损失：只留帧级 WA 70.85，只留整句 28.96）。所以「整片一个情绪」是错输出。
3. **窗长决定标签空间**（CHEAVD 原句：片段太短时「difficult to choose dimensional labeling method」；FEELTRACE 维度标注要 15–30 秒）。我的 4 秒窗**比全领域最短的还短 3.75 倍**——数值不可借，方法可借。
4. **人际一致性只有 0.2，而主流把它平均掉**（DEAM α=0.21/0.19，处理方式是 median + average）。这给 A5 的 L2 层一个机器版本：被平均掉的和层间冲突被平均掉的是同一类信息。
5. **我只对 arousal 一侧有通道**（CCC 0.810 vs 0.680；arousal 挂能量/谱动态，valence 靠和声旋律）。凡含 $v$ 的结论只能标「弱」。
6. **锚不许直译**（GlobalMood：五语言词表 644/528/870/629/283，零样本 r=0.08，MDS 面积表示「看着能译、实际分歧」）。九因子的中文词面必须从中文语料里自下而上长出来。

## 五、更新规则

- 新增文献：先在第二节表里加一行（**先写它要回答哪条问题**），再去读；读完补「读到哪」与结论落点。
- 拿不到：写进第四节，不猜内容；**要区分「我催过没拿到」与「我事后才发现需要」**。
- 任何一条结论要进理论正文，必须能指回本文某一行 + 本地转录稿行号。
