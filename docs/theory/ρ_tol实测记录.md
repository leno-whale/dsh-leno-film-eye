# ρ_tol 实测记录（§12.4c 第一跑）

> 2026-10-31。理论正文见 [倾向阻断论](倾向阻断论.md)（v2.2）。
> 本文只补一件事：§12.4(c) 写了「ρ_tol 有测量实验」，但它一直没跑——**0.9 仍然是拍的**。现在跑了一次。
> 口径写在 `rtol.mjs` 文件头，**先写死再跑**（落地计划 §一·2 的纪律）。

## 一、素材与口径

- 素材：《红泪石戒指》MV（B 站 1080P，3:37），音轨 AAC 48 kHz 立体声 ~190 kbps。
  **源本身已有损**——测的是「再压一道」的增量损失，不是绝对保真，这条不许省。
- 参照 x：音轨按 `pcm_s16le` 位精确提出。
- D(x)：AAC-LC 320 kbps / 128 kbps（ffmpeg 内置编码器），不动采样率与声道；单声道化在解码侧做，与帧算子一致。
- 特征集（**全部复用本仓库 lib 的算子，不另造尺子**）：
  - A 窗口 RMS 序列——lib/align.js 的 8 kHz 帧算子，线性域，w ∈ {0.5, 4, 30} s（4 s = film_align 默认）；每个窗的 RMS 视作一个 f，所以 sup 是最严的读法
  - B 平均窗 RMS；C 峰值窗 RMS
  - D volumedetect 的 mean / max
  - E silencedetect（−40 dB / 0.5 s）静段条数与总时长
- 统计：ρ̂ = 1 − sup_f |f(x) − f(Dx)| / max(|f(x)|, ε)，ε = 1e-4（≈ −80 dBFS）。

## 二、结果

| 对比 | sup 相对差 | ρ̂_tol |
|---|---|---|
| x → 320k | 0.0491 | **0.9509** |
| x → 128k | 0.0685 | **0.9315** |
| 320k → 128k（§12.4c 字面例） | 0.0345 | 0.9655 |

最紧的特征始终是 **A·0.5 s 窗**；窗越宽越稳（4 s：sup 0.027/0.046，30 s：0.021/0.037）。几个可读的锚点：

- 窗内最大偏移：**0.62 dB**（0.5 s @128k）；film_align 实际用的 4 s 窗只有 **0.41 dB**。
  对照：这片报过的最小效应是 1:22 的 −6.6 LU——压缩带来的噪声比它小一个量级。
- 静段清单完全不动（1→1 条、5.6 s→5.6 s；320k 下位级相同，128k 下时长差 3.7e-6）。
- max_volume 三个对比全部位级相同；mean_volume −0.1 dB（320k）/ −0.2 dB（128k）。

## 三、判读（按跑之前写死的两条执行）

1. ρ̂(x→320k) = 0.9509 ≥ 0.9 ⇒ **§1.2 拍的 0.9 在「再压一道 320k」口径下成立**。
2. ρ̂(x→128k) = 0.9315 ≥ 0.9 ⇒ 128k 也过线，但余量只剩 0.03，且全部来自 0.5 s 窗
  （实际工具用 4 s 窗，单看该特征 ρ̂ = 0.954）。

**一句话**：S 的定义不用改；§13.1 里「ρ_tol 没有值」可以改成
「0.9 在该片、AAC、再压一道口径下测得（0.95/0.93），跨片未测」。

## 四、边界（照抄纪律，一条不省）

1. **单素材**：只对《红泪石戒指》成立。换素材 ρ̂ 大幅变动 ⇒ 不外推——这正是 §12.4(c) 写的「什么能打死它」，它还没被触发，但也没被排除。
2. **单编码器族**：AAC-LC。opus / mp3 没测。
3. **增量损失**：源已是 ~190k AAC。「再压一道 128k 过线」不等于「首编 128k 素材进 S」。
4. ε = 1e-4 的地板在静段窗起作用；换 ε 会动最紧那几窗的读数。
