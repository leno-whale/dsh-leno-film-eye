## 2. 尺子（三种，**不可互比**，A7）

| 标签 | 实现 | 参数 | 用在哪 | 限制 |
|---|---|---|---|---|
| `db`（她的帧算子） | 与 `lib/align.js` 同式 | 8 kHz 单声道、4 s **满窗**、20·log10(RMS)、静音钳 −90、一位小数 | 全部 | 未加门限的 RMS，不是 LUFS（幅度会偏大，见 README 更正） |

| `demucs+pyin` | htdemucs 分 vocals → pyin | 同上，fmax 1000；**db 仍取原混音** | demucs 试点 | 分离残留低频串音；模型与权重未入库 |

## 6. 已知缺口（不许当成已解决）

1. **无音频哈希**，素材未入库；换机无法字节级复核。
2. **三种尺子不可互比**；CREPE 与 pyin 的数值禁止进同一张表。
3. **情绪模型 `no-model`**（essentia 未装）→ 经验命题 7 一条旁证都没有。
4. **3 dB 阈值是在 6 dB 失败之后才开的**；判读未改、结果分表，但选择本身不盲。
5. **`沉` 的标签含语调/旋律污染**，声调与句末未标注；3 dB 的 0.59 只能读作操作性盲区。
6. **MV 侧尺子未通过**：分离后 IQR 仍 4.95，且出现 +24 半音换声区跳变。
7. **访谈只有 4 支**（<5），只报 pooled，不给跨片分布。
8. **参数**：除 $\rho_{\rm tol}=0.9$（拍的值）外全部无值；本文所有数**不含任何理论参数**。
